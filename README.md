**Radial Array** is a lightweight, procedural add-on for Blender that instantly adds a customizable radial array modifier to any mesh. Powered by Geometry Nodes, it’s fast, non-destructive, and built for modern Blender workflows.

**Features:**

* Instantly accessible from the right-click Object Context Menu.

* Control object count, radius, and spin offset.

* Rotate around X, Y, or Z axis.

* Alignment options: face objects outward or along the circular path.

**Compatibility:** Blender 4.2 to 5.0+

**Installation:**
*Method 1 (Easiest):* Download the .zip file, and simply drag-and-drop the file directly into your Blender window. Click "Install Extension" when prompted.
*Method 2:* Go to Edit > Preferences > Get Extensions, click the drop-down arrow in the top right, select Install from Disk, and choose the .zip file.
